# Название: Точное время (домашнее задание №2)
## Автор: Сайкин Михаил Сергеевич, бТИИ-261

### Описание задачи

### Программа принимает одно целое число — общее количество секунд. Её цель — перевести это значение в стандартный формат часов, минут и секунд.
### Основная особенность алгоритма заключается в динамическом выводе: если итоговое количество часов равно 0, слово «час» (и само значение часов) не выводится на экран.
### Логика вычислений и условия:
### • Количество часов определяется как: hours = total_seconds / 3600
### • Остаток секунд после подсчета часов: remainder = total_seconds % 3600
### • Количество минут определяется из остатка: minutes = remainder / 60
### • Количество секунд: seconds = remainder % 60
### • Условие скрытия часов реализовано выражением: if (hours > 0) (выводить часы), иначе выводить только минуты и секунды.
